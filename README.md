This repository contains FILTER-LLM pipelines, prompts, and scripts used in the paper:

> *Benchmarking Large Language Models for Lemmatization and Translation of Finnic Runosongs*  
> Pivovarova et al., IWCLUL, 2025

[[Paper](paper.pdf)] [[Slides](presentation.pdf)]

The scripts take as an input FILTER data from this repository: https://github.com/hsci-r/filter-pipeline . The code has been tried on the LUMI supercomputer, see example batch jobs in ../sbatch. 

The manually annotated dataset is published under the [annotations](annotations/) folder.
